## TECHNICAL SPECIFICATIONS

### YouTube Video Embedding
```html
<iframe 
  width="100%" 
  height="600" 
  src="https://www.youtube.com/embed/{video_id}"
  frameborder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen>
</iframe>
```

### Database Schema
```sql
-- YouTube Videos Cache Table
CREATE TABLE youtube_videos (
  id INTEGER PRIMARY KEY,
  exercise_name TEXT,
  video_id TEXT UNIQUE,
  title TEXT,
  channel TEXT,
  duration_seconds INTEGER,
  difficulty TEXT,
  thumbnail_url TEXT,
  cached_at TIMESTAMP
);

-- Watch History Table
CREATE TABLE video_watch_history (
  id INTEGER PRIMARY KEY,
  video_id TEXT,
  title TEXT,
  watched_at TIMESTAMP,
  watch_duration_seconds INTEGER
);
```

## TROUBLESHOOTING

### Issue: Video doesn't play
**Solution**:
1. Check internet connection
2. Try "Open on YouTube" link
3. Clear browser cache (Ctrl+Shift+Delete)
4. Restart browser

### Issue: Thumbnail not showing
**Solution**:
1. Verify network connectivity
2. Refresh page (F5)
3. Try different browser
4. Check if images are blocked

### Issue: Watch history not saving
**Solution**:
1. Check workout_history.db file permissions
2. Verify disk space available
3. Restart application
4. Check database integrity
