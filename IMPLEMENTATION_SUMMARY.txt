⚠️  7. 제약사항 및 한계
═══════════════════════════════════════════════════════

▸ 보행 감지
  • 발목 y좌표 변화(±10픽셀) 기반 → 카메라 거리/각도에 민감
  • 최소 300ms 간격으로 걸음 판정 → 매우 빠른 보행 인식 불가
  • 가로 방향 보행만 감지 (깊이 정보 없음)
  • 가만히 서 있고 발을 오르락내리락 하는 경우 오감지 가능

▸ 케이던스 계산
  • 발목만 사용 → 정확도 ±20% 범위
  • 무릎 굽히는 각도 고려 없음
  • 보폭은 고려하지 않음

▸ 좌우 균형 평가
  • 발의 좌우 위치 비율로만 판단
  • 실제 근력/무게 중심 균형은 평가하지 않음
  • 카메라 각도에 민감함

▸ 보행 대칭성
  • 걸음 간격 일정성 기반만 평가
  • 보행 자세의 질적 평가는 아님
  • 100% 대칭 보행은 현실적으로 불가능하므로 참고만

▸ 자세 평가
  • 어깨/엉덩이 높이, 상체 기울기만 평가
  • 무릎 굽힘, 발목 위치, 보폭 등은 평가하지 않음
  • 목/머리 위치는 평가하지 않음

▸ 환경 제약
  • 실내에서만 테스트됨 (야외 미테스트)
  • 여러 명의 보행 분석 미지원 (1명만)
  • 비디오 녹화 기능 미구현
  • 카메라 필수 (카메라 없으면 작동 불가)

📞 14. 문제 해결
═══════════════════════════════════════════════════════

Q1: 카메라가 작동하지 않음
A:  1. 카메라가 연결되었는지 확인
    2. 환경 설정에서 카메라 인덱스 변경 시도 (0→1→2)
    3. 다른 앱이 카메라를 사용 중인지 확인
    4. 카메라 드라이버 재설치

Q2: 걸음이 감지되지 않음
A:  1. 카메라에 발이 충분히 보이는지 확인
    2. 조명을 밝게 조정
    3. 천천히 보행 (너무 빠르면 불가)
    4. 발목 움직임이 충분한지 확인

Q3: 케이던스가 비정상적
A:  1. 카메라 각도 확인 (정면 촬영)
    2. 카메라-사용자 거리 조정 (1-2미터)
    3. 발목이 위아래로 충분히 움직이는지 확인
    4. 조명 개선

Q4: 앱이 느리거나 먹통
A:  1. Streamlit 종료 후 재시작
    2. Python 프로세스 정리
    3. 메모리 충분한지 확인
    4. 카메라 프레임 비율 확인

Q5: 기록이 저장되지 않음
A:  1. 보행 종료 버튼을 반드시 클릭했는지 확인
    2. 데이터베이스 파일 권한 확인
    3. 디스크 공간 확인
    4. 에러 메시지 확인
