### B. 현재 메뉴 구조 (8개)
1. ✅ 홈 대시보드
2. ✅ 실시간 AI 관절 인식
3. ✅ AI 스쿼트 자세 분석
4. ✅ AI 보행 분석
5. ✅ 운동 기록 및 통계
6. ✅ 생활 습관 관리
7. ✅ 안전 관리
8. ✅ 환경 설정

### C. 현재 데이터베이스 스키마

#### workout_records 테이블 (스쿼트)
```sql
- id (INTEGER PRIMARY KEY)
- workout_date (TEXT)
- exercise_type (TEXT)
- total_count (INTEGER)
- workout_seconds (REAL)
- avg_posture_accuracy (REAL)
```

#### walk_records 테이블 (보행)
```sql
- id (INTEGER PRIMARY KEY)
- walk_date (TEXT)
- duration_seconds (REAL)
- total_steps (INTEGER)
- cadence (REAL)
- avg_left_right_balance (REAL)
- gait_symmetry (REAL)
- avg_posture_accuracy (REAL)
```

### D. 현재 구현된 기능

#### 스쿼트 분석 ✅
- 실시간 관절 인식 (14개 주요 관절)
- 무릎 각도 측정
- 상체 기울기 분석
- 운동 깊이 평가 (얕음/중간/깊음)
- 운동 속도 측정 (도/초)
- 자세 정확도 계산
- 세션별 요약 통계
- 운동 기록 저장/조회

#### 보행 분석 ✅
- 실시간 보행 감지
- 걸음 수 계산 (발목 y좌표 변화)

- 좌우 균형 평가 (% 비율)
- 보행 대칭성 계산
- 자세 정확도 평가
- 보행 기록 저장/조회
- 날짜별 추이 차트

#### 기존 기능
- 생활 습관 관리 (수분 섭취, 목표 걸음 수, 수면 시간)

## 🔧 기술적 고려사항

### A. 데이터베이스 확장 (중요)

#### 신규 테이블: goals
```sql
CREATE TABLE goals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    goal_type TEXT NOT NULL,          -- 'squat', 'walk'
    target_value INTEGER NOT NULL,     -- 목표값
    created_date TEXT NOT NULL,        -- 설정 날짜
    updated_date TEXT,                -- 수정 날짜
    is_active BOOLEAN DEFAULT 1       -- 활성 여부
);
```

#### 신규 테이블: daily_goals
```sql
CREATE TABLE daily_goals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    goal_date TEXT NOT NULL,           -- 기록 날짜
    goal_type TEXT NOT NULL,           -- 'squat', 'walk'
    target_value INTEGER NOT NULL,     -- 목표값
    achieved_value INTEGER NOT NULL,   -- 달성값
    achievement_rate REAL NOT NULL     -- 달성률 (%)
);
```
