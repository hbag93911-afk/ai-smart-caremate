## 🗄️ 데이터베이스 상태

### 테이블 구조
```
workout_records (기존)
├── id: 고유 ID
├── workout_date: 운동 날짜
├── exercise_type: 운동 종류
├── total_count: 운동 횟수
├── workout_seconds: 운동 시간
└── avg_posture_accuracy: 자세 정확도

walk_records (기존)
├── id: 고유 ID
├── walk_date: 보행 날짜
├── duration_seconds: 보행 시간
├── total_steps: 걸음 수
├── cadence: 분당 걸음 수
├── avg_left_right_balance: 좌우 균형
├── gait_symmetry: 보행 대칭성
└── avg_posture_accuracy: 자세 정확도

goals (신규)
├── id: 고유 ID
├── goal_type: 목표 종류 (squat/walk)
├── target_value: 목표값
├── created_date: 생성 날짜
├── updated_date: 수정 날짜
└── is_active: 활성 여부

daily_goals (신규)
├── id: 고유 ID
├── goal_date: 기록 날짜
├── goal_type: 목표 종류
├── target_value: 목표값
├── achieved_value: 달성값
└── achievement_rate: 달성률
```

## ⚠️ 주의사항

### 카메라 사용
- 웹캠이 반드시 연결되어 있어야 함
- 카메라 권한을 허용해야 함
- 조명이 충분해야 관절 인식 정확도가 높음
- 전신이 화면에 보여야 정확한 분석 가능

### 보행 분석
- 연속적인 걷기 동작을 촬영해야 함 (최소 2-3걸음 이상)
- 발목 움직임이 명확해야 걸음 수 감지 가능
- 카메라가 정면 또는 측면에서 보행을 촬영해야 함

### 목표 관리
- 목표는 양수만 입력 가능
- 운동 또는 보행이 없는 날은 달성도 기록 없음
- 목표 달성률은 100%로 제한 (초과 달성도는 기록되지 않음)
