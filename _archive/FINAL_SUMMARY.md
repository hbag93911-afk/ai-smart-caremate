## 🎯 추가된 주요 기능 (5가지)

### 1️⃣ AI 맞춤형 운동 추천 (`workout_recommendation.py`)
- **12가지 운동 라이브러리** 완성
- **개인 프로필 기반 추천 엔진** 구현
- 체력 → 목표 → 제한사항 → 추천 (4단계)
- 추천 이유 명시 및 팁 제공

### 2️⃣ 건강 추적 모듈 (`health_tracker.py`)
- **운동별 세션 기록** 시스템
- **목표 달성률 계산** (주간, 월간)
- **개선 추세 분석** 및 피드백
- **5개 신규 데이터베이스 테이블** 추가

### 3️⃣ 유튜브 영상 연동 (`youtube_integration.py`)
- **20개+ 실제 유튜브 영상** 준비
- **앱 내 영상 임베드 재생**
- **난이도별 필터링** (초보자/중급자/고급자)
- **시청 기록 추적**

### 4️⃣ 완전한 메뉴 개편 (`ui_renderers.py`)
- **10개 메뉴** 통합 (이모지 포함)
- **7개 새로운 화면** 렌더링
- 직관적 사용자 인터페이스
- 운동별 맞춤 코칭 UI

### 5️⃣ 기존 기능 완전 보존
- 카메라 & 관절 인식 100% 유지
- 스쿼트/보행 분석 그대로 작동
- 운동 기록 & 통계 호환성 유지
- 데이터베이스 백워드 호환성

```
   ↓
4. 실시간 AI 운동 코칭
   • 카메라 시작
   • 운동 수행 (자동 카운팅)
   • 자세 피드백 받음
   ↓
5. 운동 기록 및 추적
   • 목표 설정 (주 3회)
   • 주간/월간 진행도 확인
   • 성과 분석
```

### 사용 기술
- **Frontend**: Streamlit (파이썬 웹 프레임워크)

- **Database**: SQLite3
- **Language**: Python 3.8+

### 종속성 (변경 없음)
```
streamlit
opencv-python-headless

altair
```

- SQLite 쿼리 기반 분석
- Streamlit 컴포넌트 (expandable, columns, metric)
- iframe을 통한 유튜브 임베드

## 💾 데이터 저장 위치

### SQLite 데이터베이스
```
workout_history.db
├── 기존 테이블
│   ├── workout_records (스쿼트)
│   ├── walk_records (보행)
│   └── goals (목표)
└── 신규 테이블
    ├── exercise_sessions (운동 세션)
    ├── health_metrics (건강 지표)
    ├── exercise_goals (운동별 목표)
    ├── youtube_videos (영상 캐시)
    └── video_watch_history (시청 기록)
```

- `health_tracker`: 건강 추적
- `youtube_searcher`: 영상 검색
- `video_tracker`: 시청 기록

## ⚠️ 중요 사항

### 보안 및 윤리
✅ **질병 진단 금지**
- 카메라 분석은 건강 보조 목적
- 질병이나 신체 상태를 확정할 수 없음
- 의료 조언이 아님

✅ **신체적 제한사항 고려**
- 사용자 제한사항에 맞는 운동만 추천
- 무리한 운동 추천 없음
- 안전성 최우선

✅ **개인 정보 보호**
- 로컬 저장소 사용 (클라우드 미사용)
- 데이터베이스 암호화 미구현 (필요시 추가 가능)

### API 사용 여부
❌ **YouTube Data API 미사용**
- 사전 정의된 운동 영상 사용
- 추가 설정/인증 불필요
- quota 제한 없음

✅ **향후 계획**
- Phase 2에서 API 연동 고려
- 더 많은 운동 종류 지원
- 실시간 영상 검색
