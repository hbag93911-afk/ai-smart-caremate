# 홈 대시보드 완전 개편 계획

## 🎯 현황 분석

### 기존 홈 대시보드 구조
- **위치**: app.py의 `render_home_dashboard()` 함수 (약 300줄)
- **내용**:
  - 스쿼트 통계 (4개 KPI: 운동 횟수, 시간, 목표 달성률, 상태)
  - 최근 운동 기록 (최근 5개)
  - 날짜별 운동 횟수 추이 차트
  - 보행 통계 (동일 구조)
  - 최근 보행 기록
  - 날짜별 보행 걸음 수 추이 차트

### 기존 대시보드의 문제점
1. 과거 운동(스쿼트, 보행)에만 중심
2. 맞춤 운동 추천이 없음
3. 유튜브 영상이 없음
4. 초보자 사용자 고려 부족
5. 카메라 분석 결과가 미반영
6. 다음 단계 가이드 없음

## 🏗️ 새로운 대시보드 구조 (4가지 섹션)

### 섹션 1️⃣: 상단 헤더 영역
```
┌─────────────────────────────────────────────┐
│ AI 스마트 케어메이트                        │
│ 🎯 오늘의 맞춤 운동                         │
│ 나에게 맞는 운동을 시작해 보세요!          │
└─────────────────────────────────────────────┘
```
- 앱 이름 (대형)
- 제목: "오늘의 맞춤 운동"
- 안내 문구

### 섹션 2️⃣: 맞춤 운동 추천 카드 (4개)
```
┌──────────┬──────────┬──────────┬──────────┐
│ 스쿼트   │ 스트레칭  │ 산책/걷기 │ 홈트    │
│ 하체운동 │ 유연성   │ 보행운동 │ 전신운동 │
│ ⭐⭐    │ ⭐⭐    │ ⭐     │ ⭐⭐⭐  │
│ 10분     │ 15분     │ 30분     │ 20분     │
│ [상세보기] │ [상세보기] │ [상세보기] │ [상세보기] │
└──────────┴──────────┴──────────┴──────────┘
```
- 운동 이름, 카테고리, 난이도, 추정 시간
- 클릭 → 상세 페이지 이동

### 섹션 3️⃣: 추천 유튜브 운동 영상 (4개)
```
┌──────────┬──────────┬──────────┬──────────┐
│ 썸네일   │ 썸네일   │ 썸네일   │ 썸네일   │
│ 스쿼트   │ 스트레칭 │ 걷기/산책│ 홈트    │
│ [재생]   │ [재생]   │ [재생]   │ [재생]   │
└──────────┴──────────┴──────────┴──────────┘
```
- 실제 존재하는 유튜브 영상
- 썸네일, 제목, 채널명, 조회수
- 클릭 → 앱 내 임베드 또는 유튜브 오픈

### 섹션 4️⃣: 나의 운동 관리 (오른쪽 사이드바)
```
┌─────────────────────┐
│ 오늘의 운동 통계     │
│ ─────────────────── │
│ 운동 횟수: 12회     │
│ 운동 시간: 45분     │
│ 목표 달성률: 60%    │
│ 최근 운동: 스쿼트   │
│                     │
│ 📊 주간 통계        │
│ 월 화 수 목 금 토 일 │
│ ■ ■ ■ □ □ □ □     │
│                     │
│ 🎯 운동 목표        │
│ 주 목표: 300분      │
│ 완료: 185분 (61%)   │
└─────────────────────┘
```
- 오늘 운동 통계 (횟수, 시간, 달성률)
- 최근 운동 기록
- 주간 운동 통계
- 운동 목표 진행도

  - 맞춤 운동 추천 로직

### 2️⃣ 기존 모듈 활용
- **workout_recommendation.py** (기존)
  - UserProfile, ExerciseLibrary, WorkoutRecommender
  - 추천 알고리즘 활용

- **youtube_integration.py** (기존)
  - YouTubeSearcher로 영상 검색
  - VideoWatchTracker로 시청 기록

- **health_tracker.py** (기존)
  - 운동 세션 기록
  - 주간/월간 통계
  - 건강 지표

### 3️⃣ app.py 수정
- `render_home_dashboard()` 함수 완전 개편
- 기존 기능 호환성 유지
- 세션 상태 초기화 확장

## 📊 데이터 흐름

```
1. 사용자 프로필 로드 (UserProfile)
   ↓
2. 추천 운동 생성 (WorkoutRecommender)
   ↓
3. 운동별 유튜브 영상 검색 (YouTubeSearcher)
   ↓
4. 오늘 운동 통계 조회 (HealthTracker)
   ↓
5. 대시보드 렌더링
   - 헤더
   - 운동 카드 (4개)
   - 유튜브 영상 (4개)
   - 통계 사이드바
```
