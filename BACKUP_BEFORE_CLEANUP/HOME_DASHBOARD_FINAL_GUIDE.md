## 🎯 새로운 대시보드 주요 기능

### 섹션 1: 헤더 (상단)
- 🩺 앱 이름
- 🎯 "오늘의 맞춤 운동"
- 📝 안내 문구: "나에게 맞는 운동을 시작해 보세요!"

### 섹션 2: 맞춤 운동 추천 카드 (2x2 그리드)
```
┌─────────────┐  ┌─────────────┐
│ 🏋️ 스쿼트   │  │ 🧘 스트레칭 │
│ 하체 운동   │  │ 유연성 운동 │
│ ⭐ 10-20분  │  │ ⭐ 10-15분  │
└─────────────┘  └─────────────┘
┌─────────────┐  ┌─────────────┐
│ 🚶 산책/걷기│  │ 💪 홈트    │
│ 보행 운동   │  │ 전신 운동   │
│ ⭐ 20-40분  │  │ ⭐⭐ 15-30분│
└─────────────┘  └─────────────┘
```

### 섹션 3: 추천 유튜브 영상 (2x2 그리드)
1. 올바른 스쿼트 자세 배우기 (초보자 가이드)
2. 일상적인 스트레칭 루틴 10분
3. 올바른 걷기 운동법
4. 초보자를 위한 홈 운동 15분

**특징:**
- 실제 존재하는 유튜브 영상
- 썸네일 이미지 로드
- "유튜브에서 보기" 버튼 클릭 시 유튜브 오픈

### 섹션 4: 나의 운동 관리 (통계)
**4개 KPI:**
- 🏃 오늘의 운동 횟수
- ⏱️ 누적 운동 시간
- 🎯 운동 목표 달성률
- ✅ 최근 운동

**주간 운동 통계:**
- 월~일 7일간 운동 기록
- 막대 그래프로 시각화

**운동 목표:**
- 스쿼트 목표 진행률 (회/목표)
- 보행 목표 진행률 (걸음/목표)
- 프로그레스 바로 표시

## 📞 FAQ

### Q. 기존 운동 기능이 사라졌나요?
**A.** 아니요, 모든 기존 기능이 100% 보존되었습니다. 오직 홈 대시보드 화면만 개편되었습니다.

### Q. 카메라로 운동 분석은 여전히 가능한가요?
**A.** 네, 모든 카메라 기능이 완벽히 작동합니다. 왼쪽 메뉴에서 각 운동을 선택하면 됩니다.

### Q. 유튜브 영상이 로드되지 않습니다.
**A.** 인터넷 연결을 확인하세요. "유튜브에서 보기" 버튼으로 직접 접속할 수도 있습니다.

### Q. 운동 기록이 나타나지 않습니다.
**A.** 카메라에서 운동을 완료한 후 기록이 저장됩니다. 데이터베이스를 확인하세요.

### Q. 목표 달성률이 0%입니다.
**A.** "⚙️ 환경 설정"에서 운동 목표를 먼저 설정해야 합니다.
