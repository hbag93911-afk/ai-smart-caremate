# 🎯 CareMate 고도화 개발 계획 (요약)

## 📌 현재 상태 한눈에 보기

### ✅ 완료된 기능
- CareMate (스쿼트 분석) + WalkMate (보행 분석) 통합
- 8개 메뉴 구성
- 기본 대시보드, 기록 저장/조회
- 실시간 자세 피드백

### ⚠️ 개선이 필요한 부분
| 요청 항목 | 현재 | 개선점 |
|----------|------|--------|
| **통합 건강관리 리포트** | 기본만 | 주간/월간 통계 추가 |
| **운동 목표 관리** | 세션 메모리만 | DB에 저장, 목표 수정 UI 개선 |
| **기록 삭제** | 없음 | 삭제 기능 추가 |
| **카메라 안내** | 기본만 | 거리/조명 가이드 개선 |
| **데이터 분석** | 단순 나열 | 비교 분석, 추세 그래프 |

---

## 🛠️ 개선 계획 (3단계)

### **Phase 1: 필수 개선** ⭐⭐⭐
*예상 시간: 5-6시간*

**1️⃣ 목표 관리 시스템 고도화**
- 목표를 세션이 아닌 **데이터베이스에 저장**
- 사용자가 언제든 목표 수정 가능
- 목표 달성 기록 추적

**2️⃣ 통합 건강관리 리포트 강화**
- 홈 대시보드에 **주간/월간 요약** 추가
- **주간 평균 비교** 그래프
- 현재 대비 이전 주/월 성과 표시

**3️⃣ 기록 삭제 기능**
- 개별 기록 삭제
- 선택 삭제 / 기간 삭제
- 삭제 확인 (실수 방지)

---

### **Phase 2: 기능 완성** ⭐⭐
*예상 시간: 4-5시간*

**4️⃣ 카메라 촬영 안내 개선**
- 도해가 있는 촬영 가이드
- 거리 측정 안내
- 조명 체크 기능
- 전신 인식 여부 확인

**5️⃣ 주간/월간 비교 분석**
- 이전 주와 비교 (증감률)
- 이전 월과 비교
- 개인 최고 기록(PR) 추적
- 최고/최저 하이라이트

---

### **Phase 3: 고급 기능** ⭐
*예상 시간: 4-6시간*

**6️⃣ AI 개선 제안 피드백**
- 세션 종료 후 종합 피드백
- 반복 오류 패턴 분석
- 맞춤형 운동 팁

**7️⃣ 대시보드 시각화 강화**
- 목표 진행률 프로그레스 바
- 뱃지/업적 시스템
- 월간 달력 뷰 (활동 강도 표시)

**8️⃣ UI/UX 개선**
- 모바일 최적화
- 색상 코드 추가
- 반응형 디자인 개선

## 📊 필요한 파일 변경

### 데이터베이스 (신규 테이블)
```sql
-- 목표 설정
CREATE TABLE goals (
    id, goal_type, target_value, 
    created_date, updated_date, is_active
);

-- 일일 목표 달성 기록
CREATE TABLE daily_goals (
    id, goal_date, goal_type, target_value, 
    achieved_value, achievement_rate
);
```
